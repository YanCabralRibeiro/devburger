#  Projeto DevBurger

O DevBurger é um projeto completo de e-commerce desenvolvido como parte dos meus estudos, com o objetivo de colocar em prática meus conhecimentos em desenvolvimento full-stack.
O sistema simula uma hamburgueria virtual, onde o usuário pode visualizar produtos, filtrar por categorias, adicionar itens ao carrinho e finalizar o pedido. No painel administrativo, é possível gerenciar produtos, categorias e acompanhar os pedidos em tempo real, fundamental para aprofundar meu entendimento sobre integração entre frontend e backend, manipulação de APIs, autenticação de usuários e persistência de dados em banco de dados.
